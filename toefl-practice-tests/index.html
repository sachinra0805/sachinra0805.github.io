Hosting this page on GitHub Pages

This is a single self-contained static site (index.html + the assets/ folder for the listening audio). To publish it:

  1. Create a generic-named public repository, e.g. toefl-mini-practice-tests.
  2. Upload index.html and the assets/ folder.
  3. In the repo: Settings → Pages → Deploy from branch → main / root. Your shareable link appears there.
  4. Add a file called RESULTS.md to the repo and paste each “Copy result summary” text into it to log scores over time.
